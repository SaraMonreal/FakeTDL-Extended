# FakeTDL-Extended. Objetivos y ejecución del proyecto

FakeTDL-Extended define un lenguaje inventado diseñado para demostrar cómo se puede especificar, validar y transformar mensajes binarios mediante DFDL (Data Format Description Languaje) y Apache Daffodil.

El proyecto incluye:
- Una carpeta de /project donde se carga el plugin para ejecutar el esquema DFDL y ejecuta los test.
- Una carpeta /src que implementan el lenguaje FakeTDL.
- Una carpeta /test donde estan implementados los test de prueba.

- Las especificaciones (FakeTDL-ExtendedSpecification) definen cada tipo de mensaje del lenguaje inventado.

El objetivo principal del proyecto es implementar y validar un lenguaje binario ya que las especificaciones reales de un TDL son confidenciales.
